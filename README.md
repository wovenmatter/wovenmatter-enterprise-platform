# WovenMatter Enterprise Platform

The open-source repository for the WovenMatter Enterprise platform.

This repository currently contains the project's license, contribution policies,
and repository governance. Platform source code will be imported separately.
Build, development, and deployment instructions will accompany that import.

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md) and the
[Code of Conduct](CODE_OF_CONDUCT.md). Changes to `main` require a pull request
and approval from the code owner, [@trey131](https://github.com/trey131).

## Security

Report vulnerabilities privately using the process in [SECURITY.md](SECURITY.md).
