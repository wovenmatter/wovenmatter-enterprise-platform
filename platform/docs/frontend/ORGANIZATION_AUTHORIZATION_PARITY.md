# Organization and workspace authorization parity

Reference: immutable WovenMatter commit [`04fe05090e107df92c498a4563b742978c91d933`](https://github.com/wovenmatter/wovenmatter/tree/04fe05090e107df92c498a4563b742978c91d933). Enterprise adds organization and shared workspace authorization around the proven workspace data and native history contracts. Desktop operator/device authority is not treated as an Enterprise organization role.
