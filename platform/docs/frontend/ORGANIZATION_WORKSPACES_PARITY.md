Five-harness transport, configuration and credential routing details are recorded
in the runtime parity document. Organization ownership, accounts and migrations
are recorded in `ORGANIZATION_AUTHORIZATION_PARITY.md`.

Browser adaptations include platform font fallback, responsive collapsible rails,
safe HTML artifact rendering, browser-available dictation, and server-owned
datasets accessed through authenticated APIs instead of a local desktop file
handle. Library publication shares the permanent-deletion lifecycle lane so retention cannot recreate purged storage. The browser note editor uses format-aware text and preview rather than native attributed text; New chat opens the shared agent/folder dialog, with direct creation from the empty-workspace composer. Library facets are scoped to this workspace and include agent type, sender, type, date and ordering; cross-workspace and individual agent-instance facets are omitted.

No external-provider entitlement or human authentication flow is proved
by synthetic fixtures. Final validation and any remaining acceptance gaps must
be recorded in the PR and private evidence results before preview publication.
