## SDK and upgrade preservation

Native adapter dependencies are exact lockfile pins. Existing embedded Pi source and generations are not overwritten with native CLI adapters. Bundle fingerprints include the lockfile: operators must retain the entire approved-sdk/runtime-journal store when deploying, including generations pinned by existing chats. Never repoint existing generation IDs or delete old private native sessions. The inspected preview had no populated SDK generation or native session rows; populated upgrade behavior is covered independently by deterministic migration tests.
